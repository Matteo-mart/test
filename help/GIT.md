# Documentation GIT:

## URL du repo: 
````bash
https://github.com/Matteo-mart/test.git
````

## Commande de base:
````bash
git clone https://github.com/Matteo-mart/test.git # Permet de pull le projet
git pull --rebase # Récupérer le code de Github
git commit -m "Ton message" # Faire un commit (Reste en local juste avant de pousser)
git push # Permet de push son commit dans Github, Avoir fais un pull OBLIGATOIREMENT
git reset --soft HEAD~1 # Permet d'annuler son dernier commit s'il est pas push
````
