# Installation:

## Liste:
- Godot Engine 4.x (Standart).
- VSCode + godot-tools.

## Commande sous OpenSUSE:
````bash
sudo zypper refresh # Rafraîchit les packages
sudo zypper in code # Installe VSCode
sudo zypper in godot # Installe Godot
````
## Fichier installation sous OpenSUSE:
A éxécuter:
````bash
./USERPATH/test/scripts/in_tool.sh
````
## Commande sous Windows 11:
````bash
winget install GodotEngine.GodotEngine # Installer Godot
winget install Microsoft.VisualStudioCode # Installer VSCode
````
## Fichier installation sous Windows 11:
A double cliquer:
````bash
USERPATH/test/scripts/in_tools.bat
````
